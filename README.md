# My Web Application

A simple web application built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or start a local server from this directory:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Customize

- Edit `index.html` to change the page structure and content.
- Edit `styles.css` to change the appearance.
- Edit `script.js` to add interactions and application logic.
